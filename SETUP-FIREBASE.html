SBOOKY · FIREBASE

Setup Firebase tanpa bingung

Proyek sbooky-1 dan konfigurasi Web sudah terpasang. Ikuti urutan di bawah; Storage tidak diperlukan untuk versi Coming Soon.

1. Publish Firestore Rules terbaru

  1. Klik Salin Rules. Jalankan halaman ini lewat Live Server agar tombol dapat membaca file di sebelahnya.
  2. Buka Firebase Console → proyek sbooky-1 → Firestore Database → Rules.
  3. Di editor Rules tekan Ctrl+A, lalu Ctrl+V.
  4. Klik Publish dan tunggu sampai berhasil.
Buka Rules manual

Sumber: FIRESTORE-RULES.txt yang berada langsung di samping index.html.

Wajib memakai Rules dari ZIP terbaru. Tanpa Rules ini rating, point, leaderboard, dan riwayat lengkap akan ditolak Firebase.

2. Aktifkan dan buat akun admin

  1. Authentication → Sign-in method → aktifkan Email/Password.
  2. Authentication → Users → Add user.
  3. Buat kelima akun di bawah. Alamat email hanya identitas internal; tidak perlu membuat Gmail.

3. Pasang hak admin dengan UID

  1. Authentication → Users → salin UID akun admin.
  2. Firestore Database → Data → buat koleksi bernama persis adminAccess.
  3. Document ID harus UID yang disalin, bukan Auto-ID.
  4. Tambahkan field name, tipe String, nilainya nama login admin yang cocok.
  5. Ulangi untuk lima admin. Satu UID hanya untuk satu dokumen.

Contoh SAdmin: Document ID = UID akun sadmin@admins.sbooky.invalid, lalu field name = SAdmin.

4. Upload ke GitHub dalam satu tempat

  1. Ekstrak ZIP ini.
  2. Upload seluruh file di dalamnya ke halaman utama/root repository. Jangan upload ZIP-nya saja.
  3. Taruh semua gambar di tempat yang sama dengan index.html: file1.png–file8.png, wihope.png, sbpoint.png, sbgift.png, sbshop.png, sbmissionbook.png, sbfire.png, sbleaderbook.png, sbleadertime.png, sbleaderpoint.png, dan sbleaderboard.png.
  4. GitHub Settings → Pages → Deploy from a branch → main / root → Save.

5. Aktifkan delapan buku awal

  1. Masuk Sbooky sebagai admin.
  2. Dashboard → Buku & stok → Simpan 8 buku awal.
  3. Edit stok sesuai jumlah fisik sebenarnya. Stok awal sengaja 0.

Setelah mengganti file di GitHub, tunggu Pages selesai lalu tekan Ctrl+F5.
